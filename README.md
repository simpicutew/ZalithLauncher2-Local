# ZalithLauncher 2 — Local Account Edition

A modified build of ZalithLauncher 2 with Local/Offline account support restored.

## Features

- Microsoft account support
- Local / Offline account support
- Original ZalithLauncher interface
- ARM64-v8a build

## Build

This fork currently targets ARM64-v8a Android devices.

## Credits

Based on ZalithLauncher 2 by MovTery.

The Local/Offline account functionality was restored using functionality already present in the original project.

Development and debugging were assisted by ChatGPT.
